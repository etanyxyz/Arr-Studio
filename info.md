# Arr Studio

**Sonarr & Radarr, beautifully integrated into Home Assistant.**

Arr Studio adds a cinematic sidebar panel and native Home Assistant entities for your
Sonarr and Radarr servers: recently added media with poster art, live download progress,
missing items, disk space and server health.

- Works with Sonarr v4 and Radarr v5+ over the local API
- One config entry per server; add Sonarr, Radarr, or both
- Thumbnails are proxied through Home Assistant — API keys never reach the browser
- No cloud services and no extra Python requirements

See the [README](https://github.com/etanyxyz/Home-Assistant-Arr-Integration#readme) for
installation and configuration.
